# Autumn

Autumn 0.8.1 fixes the general-planner timeout: shorter example-led instructions, bounded streamed generation and direct native matching for ordinary polite app requests prevent the repeating-link failure. General computer control stays enabled: the pinned local brain can answer, run Windows commands and operate accessible app controls. Open `C:\adu\Autumn.lnk` to start the configured local brain and hands-free profile; minimize to keep listening. Follow steps in chat and use Stop to cancel active work. This runs under your normal account and the small model can make mistakes. See [Personal launch and listening](docs/PERSONAL_LAUNCH.md).

A local Windows desktop assistant named Autumn: English push-to-talk, a female local voice and the pinned `qwen3:1.7b` planner. Phase 7 adds a futuristic animated command deck, verified model setup, per-user installer and crash recovery. This is an engineering preview: earlier accuracy targets failed and human/hardware acceptance remains incomplete.

Use `dist/Autumn-0.8.1-preview/AutumnSetup.exe` for per-user installation, or the Autumn shortcut in `C:\adu` for the configured developer build. First close asks whether to quit or keep running in the tray. A second launch brings the existing window forward and refreshes the local brain. A shared Ollama service is left running. See [User guide](docs/USER_GUIDE.md), [Troubleshooting](docs/TROUBLESHOOTING.md) and [Known issues](docs/KNOWN_ISSUES.md).

For development, run these commands from this folder in PowerShell:

```powershell
.\tools\dev.ps1 run
.\tools\dev.ps1 test
.\tools\dev.ps1 lint
.\tools\dev.ps1 build
```

The measured environment is `.venv-qt-compat` with project-local CPython 3.12.10. Reproduce dependencies with the local `uv` tool and `requirements-phase7.lock` using `--require-hashes`; do not install from the unpinned input file. Phase 7 adds no dependencies. Older environments and locks are preserved. Build the app with `packaging/build.ps1`, then the installer with `packaging/build_setup.ps1`.

Stop is **Ctrl+Alt+Backspace**. Hands-free mode accepts “Autumn, …” and continues in the tray. For manual capture, enable voice, then hold **Ctrl+Alt+Space** or **Hold to talk**. Voice setup also offers toggle recording; every recording is bounded to 20 seconds. Stop and microphone-off discard unfinished voice work independently of recognition and the model. Normal launches use the saved hands-free preference; login startup and isolated diagnostics keep the microphone off.

**Voice setup** provides local file checks, microphone/speaker selection, a four-second recording test, editable recognized text, female voice volume/speed and explicit playback tests. Audio stays in memory; microphone tests never run commands. Sending edited text creates a new typed request. Playback suspends recording and adds a 300 ms acoustic tail. Lessac/Piper is primary; Windows Zira is the default-speaker fallback, with text available if neither voice works. Wake listening remains calibration-locked until its measured checks pass.

Speech files stay outside the executable in `models/stt` and `models/tts`, with exact SHA-256 checks before loading. The developer build points to this project's models; a moved installation can select its own verified local models folder. It never downloads missing files automatically. First-run setup is re-runnable in Voice setup and includes a diagnostics export preview without audio, recognized words or device names. For a synthetic-only test, use `--speech-probe-report <report.json> --data-dir <isolated-folder>`; it opens neither microphone nor speakers and dispatches no actions.

Settings and redacted activity are stored under `%LOCALAPPDATA%\Autumn\`. Activity retains seven days by default and can be cleared. Typed input stays in memory, including transient worker messages, and is never written into history or diagnostics. Corrupt settings are preserved in a recovery copy before safe defaults are created. History clearing is ordinary deletion, not secure erasure. Exported screenshots remain separate user files.

To get started, open **Apps and folders**, import installed apps or choose an executable/shortcut, inspect its target, add aliases and enable it with **Review & save**. Imports skip shell launchers and shortcuts with arguments. Register extra folders and websites explicitly on the same page. Default search roots are Documents and Downloads; Settings controls each capability and the screenshot destination.

Autumn starts the installed local Ollama server if needed and warms the pinned model when opened. **Settings → Check local brain** retries verification and warm-up. The adapter contacts only literal `127.0.0.1:11434`, ignores proxy/redirect settings, rejects remote models and checks the digest before and after generation. It never downloads or updates a model automatically. The measured default is CPU; GPU acceleration remains unverified. The baseline digest is recorded in Settings/contracts and reports.

Exact commands run before model routing and keep working if Ollama is unavailable. Turn off **Flexible English commands** to use them exclusively. **Save memory** releases the model after each request; otherwise Autumn refreshes its five-minute warm lease while running. Startup warming is asynchronous and can take up to 40 seconds after server startup. Quit never stops the separate Ollama runtime.

With General control off, model replies pass the original strict live-registry/origin checks, with a 15-second planning deadline and no generated code. With it on, unmatched requests enter a separate bounded local tool/observation loop: up to ten steps, 20 seconds/256 tokens per model choice and 35 seconds per Windows command. Repeating output stops early; one invalid-plan repair can run before any new action. Ordinary positive courtesy phrases use the exact native matcher immediately. Conversation and short clarification are available. Commands run through stdin in an owned cancellable process tree; no automatic elevation is provided. Identified destructive/external effects get a concrete review; this is heuristic, not a security sandbox. Completed effects remain after Stop. History retains outcome metadata, not scripts or user text. The earlier finite-grammar held-out results are not general-agent accuracy evidence.

**Dictation:** refresh supported windows, choose a standard Windows Edit/RichEdit field, and enter a single line or choose the next hold-to-talk recording as dictation. Request the exact preview, return to that app and focus the field. Confirm with **Ctrl+Alt+Y**, cancel with **Ctrl+Alt+N** or Stop. The overlay does not request focus; approval is single-use and expires in 30 seconds. Password/read-only/elevated fields, control characters and changed targets are refused. No Enter, shortcut or clipboard paste is sent; partial or uncertain input is never retried. Native foreground/delivery acceptance is still unverified because Windows activation calls failed during the unattended trial.

**Routines:** add up to five individual supported commands in Routines, reorder/delete them, review the preview and save a unique name. Use Run or `run routine <name>`. Steps use current reviewed targets and the initiating request's permissions. They execute in order and stop on failure, showing completed effects. No nesting, dictation or unregistered URLs in saved routines.

**Wake:** always off at launch. In Wake and desktop, verify files and complete measured calibration before arming the pretrained phrase **hey jarvis** (the assistant is still Autumn). Calibration requires 50 intentional attempts with at least 45 detections, two active hours of household audio with at most two false wakes, and a five-minute CPU window below 5% on mains. Device/default endpoint, model or threshold changes invalidate the profile. Calibration never runs commands or saves audio. Wake-origin commands cannot dictate or open unregistered URLs. Playback closes the listener before speaking; Stop, microphone-off, lock, sleep and Quit disarm it. Owner room/speaker and physical power trials remain pending, so no wake acceptance is claimed.

**Desktop:** the tray shows microphone/task state and offers Open, Stop, microphone-off and Quit. First close asks whether to stay in the tray or quit and remembers the explicit choice. Keeping it running preserves the microphone state. Login startup is optional in the standalone app and stays off until explicitly selected; it never enables voice. New profiles show bounded animations; existing reduced-motion choices are preserved. The header motion toggle disables animations; pages scroll on smaller displays. Qt scale-2 layout checks pass; Narrator, actual Windows 200% scaling and physical sleep/Modern Standby/battery trials remain unverified.

Try `what can you do?`, `open <reviewed app or folder name>`, `open https://example.com`, `set volume to 35 percent`, `mute`, `unmute`, `play pause`, `next track`, `previous track`, `take a screenshot`, `screenshot all monitors`, or `find spreadsheet budget in Downloads`. Use exact registered names; fuzzy matches only suggest names. One command at a time; negations, extra instructions and shell text do not execute. The URL example opens your browser only when you explicitly request it.

Search reads filenames inside configured roots, skips reparse points and excluded dependency/system folders, and shows at most 20 matches. The fallback scans for at most 10 seconds / 200,000 entries. Limits and inaccessible entries produce partial results. **Show folder** revalidates a selection, expires after 30 seconds, and opens its containing folder. It does not execute found files. Browser and folder handoff and uncertain media delivery are labelled unverified; actions are never automatically replayed after uncertainty.

For an isolated self-closing UI trial, set `PYTHONPATH` to `src` and run `python -m autumn.main --data-dir <project-test-folder> --phase3-smoke-report <project-report.json>` with the project interpreter. It enters fixed input into Autumn's own controls, searches disposable filenames and validates a local-model capabilities reply. It saves metadata and disposable window screenshots. Older Phase 1/2 trial flags remain available. An explicit isolated data directory is required; the standalone executable accepts the same options.
