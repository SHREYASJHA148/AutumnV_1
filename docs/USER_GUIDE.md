# Autumn preview — getting started

For the owner's configured 0.7.1 build, use the Autumn shortcut in `C:\adu`. The local brain starts automatically and the saved personal profile enables hands-free listening on normal launch, including while minimized. Say “Autumn, open Spotify”. Installed apps/common folders are discovered automatically; other local paths can be opened explicitly. [Personal launch and listening](PERSONAL_LAUNCH.md) supersedes the older manual-start instructions below for this profile. Stop/microphone-off pauses listening; login startup keeps the microphone off.

Autumn runs on your Windows computer with the pinned local `qwen3:1.7b` brain, English recognition and a female Lessac voice. This engineering preview has incomplete acceptance checks; read KNOWN_ISSUES.md before relying on it.

1. Run AutumnSetup.exe, read the bundled notices, accept the preview terms and select Install for me. Setup uses `%LOCALAPPDATA%\Autumn\application`, requires 12 GB free and does not require administrator rights. Click Open Autumn after installation. The developer build can also run directly.
2. In Setup and release, check local files and free space. Review the separate model/voice licenses. Choose explicit downloads or import from an existing models folder containing the pinned `stt`, `tts` and `wake` files. Downloads verify exact sizes and SHA-256; interrupted owned downloads can resume. Keep the voice license card beside the voice. No models are downloaded on launch.
3. Ollama is a separate prerequisite. Install it and explicitly obtain `qwen3:1.7b`; Autumn starts the installed local server and warms that pinned model when opened. Use Check local brain to retry. Autumn rejects a changed digest, remote models and non-loopback addresses. The frozen digest is in provenance.json. Flexible commands remain unavailable if it differs; exact supported commands still work. Do not substitute a similarly named model.
4. In Apps and folders, import applications, inspect each executable/shortcut and save the reviewed entry and aliases. Add approved folders and websites. Try `help`, then `open <reviewed app alias>`. Screenshot destinations and enabled capabilities are in Settings. Autumn supports a bounded catalog of actions; it has no arbitrary shell/code execution or general chat.
5. In Voice setup, check the files, choose your built-in microphone/speakers and explicitly run the microphone and playback tests. Enable voice, then hold Hold to talk or Ctrl+Alt+Space. Recording lasts at most 20 seconds. The displayed transcript can be corrected and sent as a fresh typed request. Audio is processed locally in memory.

The command deck shows actual task and microphone state. Its orbit animation is decorative; recording amplitude reacts only to real audio levels. Hover and press feedback, focus outlines and page fades remain bounded. The top Stop button keeps its position and size. Turn off motion in the header; this choice is remembered. Motion pauses while the app is hidden or inactive.

Stop or Ctrl+Alt+Backspace cancels the queue, playback, pending approval and unfinished input. Microphone off discards voice work. Already accepted Windows effects cannot always be undone. Quit from the tray stops Autumn-owned workers; the separate Ollama service and apps previously opened stay running. Closing the main window asks whether to quit or keep running in the tray, then remembers your choice. Login startup is an explicit option and always starts with voice off.

Dictation is limited to standard Edit/RichEdit controls. Select a supported target, review one exact line, return to its field and approve with Ctrl+Alt+Y within 30 seconds. Ctrl+Alt+N cancels. Autumn refuses changed, password, read-only or elevated targets and never presses Enter or retries uncertain delivery. Its native delivery trial is pending. Routines contain up to five reviewed supported steps and stop on failure. Wake mode uses the pretrained phrase hey jarvis even though the assistant is Autumn; it stays off until measured calibration passes.

Settings, history and models live under `%LOCALAPPDATA%\Autumn`. History contains outcome metadata, not your words, and defaults to seven days. Clear it in Activity. Diagnostic exports preview redacted data before saving; raw audio and transcripts are excluded. Personal screenshots remain separate files in your chosen folder.

To uninstall, first Quit Autumn, then use Windows Installed apps → Autumn engineering preview, or run the retained maintenance executable in the `maintenance` folder with `--uninstall`. Removal deletes only unchanged installed application files, retaining settings, history, downloaded models, unknown/modified files and the maintenance utility. The installer and downloaded package remain wherever you saved them. Ollama and its cache are separate. After uninstall and closing maintenance, you may manually remove the retained Autumn folder if you want to erase those files; ordinary deletion is not secure erasure. Upgrades retain unknown/modified old files in an `application.previous-*` folder.
