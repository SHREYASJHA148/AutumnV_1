# Remaining interactive acceptance

The owner authorized unattended implementation, not invented human results. Phases 5 and 6 are implemented; this checklist remains pending. Use ordinary-user access, disposable apps/test folders, and explicit microphone controls. No audio is saved.

1. **Dictation:** use a disposable standard Windows Edit/RichEdit target, choose it in Dictation, preview a public single line including Unicode, then manually return to its edit field. Confirm with Ctrl+Alt+Y. Verify exact output and that the overlay never changes focus. Check the password control is excluded, changed text needs a new preview, expiry/cancel/Stop prevents input, focus stealing halts partial delivery, and no timeout/restart duplicates input. The unattended native probe failed at a Windows activation call; do not force focus or bypass Windows restrictions.
2. **Routines:** use only disposable reviewed targets, review/reorder/delete/save a routine, run it typed and by hold-to-talk, then make an intermediate target unavailable. Check it stops at that step, shows completed effects, preserves origin limits and never retries uncertain actions.
3. **Wake files/profile:** select the intended built-in microphone, check pinned wake files, keep the laptop on mains, and leave voice startup disabled. Calibration is a separate explicit microphone opt-in. A change to input/default endpoint, threshold or model requires matching calibration.
4. **Intentional trials:** press Next intentional attempt, wait for Listening, say hey jarvis once within five seconds, and repeat until 50 independent attempts are recorded. At least 45 detections are needed. Wake detection ends the trial; it never dispatches a command during calibration.
5. **Household trial:** explicitly start 120 minutes of normal household audio, including media through the speakers. Only active listening counts; playback/pauses are excluded. At most two false wakes are allowed. The same run records a five-minute normalized CPU window on mains; CPU must stay below 5%. Stop and save the measurements. Synthetic silence/noise tests do not satisfy this gate.
6. **Runtime:** after accepted calibration, explicitly arm wake. Say the phrase, pause, then give a disposable command. Check wake cannot dictate or open an unregistered URL, including through a routine. Verify cooldown, playback suppression/tail, microphone-off, Stop, locked session, classic sleep, Modern Standby and Quit. A restart must leave the microphone and wake off.
7. **Desktop/accessibility:** verify tray and window states match, first-close choice is remembered, Quit stops owned processes, and optional login startup stays off unless deliberately enabled. Check full Tab/Shift+Tab/keyboard operation and Narrator on every page and confirmation. Repeat at actual Windows 200% scaling; the existing automated scale-2 test is a Qt layout check, not a Narrator pass.
8. **Power and previous gates:** measure battery drain during a wake run without changing safety defaults, then finish the Phase 4 owner 100-utterance, GPU end-to-end, real device/default-change, disconnected local-task and ten-minute network-trace trials. Preserve the Phase 3 accuracy failures; do not tune or rerun RC1. No complete-version-1 declaration until the chosen release tier's conditions pass.
